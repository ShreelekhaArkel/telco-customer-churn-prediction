# Telco Customer Churn Prediction

## Project Overview
A machine learning project that aims to predict customer churn in the telecommunications industry.

The project uses customer information such as tenure, contract type, monthly charges, and service usage to predict whether a customer is likely to leave the company.

## Objectives
- Predict customer churn using machine learning.
- Explain individual predictions using SHAP.
- Identify customers who should be prioritized for retention.
- Develop an interactive application using Streamlit.

## Technologies
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn
- SHAP
- Streamlit

## Project Status
Currently in Week 1: Data Understanding and Exploratory Data Analysis (EDA).
